# Digital Literacy Companion

A user-friendly chatbot designed to help parents and elderly users navigate the digital world with confidence and ease.

![Digital Literacy Companion](https://img.shields.io/badge/Digital_Literacy-Companion-blue)

## About

The Digital Literacy Companion is a Streamlit-based web application that provides clear, jargon-free guidance on common digital topics through a simple chatbot interface. The companion focuses on making technology more accessible by breaking down complex concepts into easy-to-understand explanations and step-by-step instructions.

## Features

- **Simple Chat Interface**: Ask questions in everyday language
- **Topic Categories**: Browse common questions by category
- **Step-by-Step Guidance**: Clear instructions for digital tasks
- **Resources Section**: Links to trusted external resources
- **Feedback System**: Rate responses for helpfulness
- **Accessible Design**: Large text, good contrast, simple navigation

## Topics Covered

- Internet Basics
- Online Safety & Privacy
- Social Media
- Email & Communication
- Smartphones & Apps
- Online Entertainment
- Digital Health & Wellbeing

## Prerequisites

- Python 3.7 or higher
- pip (Python package manager)

## Installation

1. Clone this repository:
   ```
   git clone https://github.com/yourusername/digital-literacy-companion.git
   cd digital-literacy-companion
   ```

2. Install the required packages:
   ```
   pip install streamlit nltk pandas
   ```

3. Download NLTK data:
   ```python
   import nltk
   nltk.download('punkt')
   nltk.download('stopwords')
   nltk.download('wordnet')
   ```
